# Skills Repository

This repository contains local skills for agent workflows.  
Each skill is self-contained in its own folder and includes a `SKILL.md`.

## Structure

- `.agents/skills/`: all available skills
- `AGENTS.md`: local environment and dependency guidance for agents
- `THIRD_PARTY_NOTICES.md`: third-party attributions and notices
